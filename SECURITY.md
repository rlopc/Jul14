# Security Policy

## Supported Versions

Jul14 has no releases yet. Only the latest commit on `main` is supported.

## Reporting a Vulnerability

Do not disclose vulnerabilities publicly. Report them privately through [GitHub private vulnerability reporting](https://github.com/rlopc/Jul14/security/advisories/new).

Reports are handled on a best-effort basis. You will be notified when the report is accepted or declined, and credited in the published advisory unless you prefer otherwise.
